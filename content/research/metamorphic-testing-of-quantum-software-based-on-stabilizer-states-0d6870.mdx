# Metamorphic Testing of Quantum Software based on Stabilizer States

> **Source:** Originally published on [arXiv quant-ph](https://arxiv.org/abs/2611.18838) on November 17, 2026.

arXiv:2611.18838v1 Announce Type: new Abstract: A major challenge in quantum computing is to systematically check if a quantum program implements its desired functionality. For classical programs, testing is widely used; each test case comprises a pair of sample input and expected output to be compared with the actual output. To increase the number of test cases, however, one has to solve the test-oracle problem: for each additional test input one has to know the correct output. Metamorphic testing tackles this problem by utilizing metamorphic relations between input and output domains to automatically derive new test cases from existing ones.
