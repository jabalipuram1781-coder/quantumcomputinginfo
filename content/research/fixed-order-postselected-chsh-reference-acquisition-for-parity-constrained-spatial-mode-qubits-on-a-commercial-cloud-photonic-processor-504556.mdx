# Fixed-order postselected CHSH reference acquisition for parity-constrained spatial-mode qubits on a commercial cloud photonic processor

> **Source:** Originally published on [arXiv quant-ph](https://arxiv.org/abs/2608.18153) on August 20, 2026.

arXiv:2608.18153v1 Announce Type: new Abstract: We report a fixed-order Clauser-Horne-Shimony-Holt (CHSH) acquisition and reporting protocol for two encoded photonic qubits on Quandela's commercial, cloud-accessible Belenos processor, executed end-to-end by external users through the public cloud interface. Each logical qubit is a two-dimensional spatial-mode subspace in the seven-dimensional zero-sum sector of an eight-mode single-photon register, and a target postselected linear-optical controlled-$Z$ (ideal success probability $1/9$) couples the registers on $16$ of $24$ modes. The primary quantity is the operational CHSH score $S$ on accepted logical coincidences, with each complete four-setting pass as the experimental unit.
