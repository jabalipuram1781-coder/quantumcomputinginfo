# Threshold-Free Symmetry-Enriched Topological Quantum Memory

> **Source:** Originally published on [arXiv quant-ph](https://arxiv.org/abs/2611.07017) on November 6, 2026.

arXiv:2611.07017v1 Announce Type: new Abstract: We show that non-Abelian symmetry enrichment can protect a toric code memory against incoherent electric noise at any bond error probability $p\in[0,1]$. For a toric code on the honeycomb lattice coupled to $Sp(N)$ rotors, with electric anyons carrying the fundamental representation, we construct an efficient minimum-weight decoder whose logical error probability decays exponentially with system size for $N\ge40$, a conservative sufficient bound. The same decoder also rules out strong-to-weak spontaneous symmetry breaking in the fundamental channel of $Sp(N)$ under the corresponding local decoherence in two dimensions.
