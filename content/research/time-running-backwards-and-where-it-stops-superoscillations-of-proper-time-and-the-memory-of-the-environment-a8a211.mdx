# Time Running Backwards, and Where It Stops: Superoscillations of Proper Time and the Memory of the Environment

> **Source:** Originally published on [arXiv quant-ph](https://arxiv.org/abs/2611.12971) on November 11, 2026.

arXiv:2611.12971v1 Announce Type: new Abstract: A quantum system prepared in a superposition of proper times - a clock whose worldline is superposed, or a clock at rest in a superposed gravitational potential - evolves, in each branch, by the same dynamics for a different duration.
