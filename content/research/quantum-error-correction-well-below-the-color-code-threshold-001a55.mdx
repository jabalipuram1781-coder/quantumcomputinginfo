# Quantum error correction well below the color code threshold

> **Source:** Originally published on [arXiv quant-ph](https://arxiv.org/abs/2610.24077) on October 20, 2026.

arXiv:2610.24077v1 Announce Type: new Abstract: Quantum error correction enables scalable fault-tolerant quantum computation by suppressing logical errors exponentially with code distance once physical error rates fall below a critical threshold. Here we demonstrate below-threshold operation of triangular color codes with distances $d=3,5,$ and $7$ on Quantinuum's Helios trapped-ion quantum processor.
