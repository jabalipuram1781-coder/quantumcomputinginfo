# Pauli-string grouping for VQE measurement reduction on a sparse-connectivity quantum annealer

> **Source:** Originally published on [arXiv quant-ph](https://arxiv.org/abs/2609.20861) on September 21, 2026.

arXiv:2609.20861v1 Announce Type: new Abstract: The Variational Quantum Eigensolver (VQE) requires a large number of measurements to evaluate molecular Hamiltonians. Expressing a molecular Hamiltonian as a linear combination of Pauli strings creates a measurement bottleneck: non-commuting Pauli strings cannot be measured simultaneously. Consequently, mutually commuting Pauli strings must be grouped and measured together to minimise the number of quantum-state preparations. This task maps to the minimum clique cover problem on a commutativity graph, an NP-hard problem typically addressed using classical heuristics.
