# High-fidelity quantum gate learning via physics-informed neural networks

> **Source:** Originally published on [arXiv quant-ph](https://arxiv.org/abs/2611.03851) on November 4, 2026.

arXiv:2611.03851v1 Announce Type: new Abstract: We propose a physics-informed neural network (PINN) approach for high-fidelity quantum gate learning in both one- and two-qubit systems. We train a PINN using the time-dependent Schr\"\{o\}dinger equation, where smooth control fields with fixed boundary conditions are obtained by minimizing a loss function that considers model dynamics, gate error, physical constraints, regularization terms, and multiple initial conditions. Training considers pairs of mutually unbiased bases, while independent validation combines Haar-random input states with the average gate fidelity.
