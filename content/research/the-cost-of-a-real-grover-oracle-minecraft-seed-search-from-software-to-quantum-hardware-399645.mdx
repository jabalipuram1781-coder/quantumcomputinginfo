# The Cost of a Real Grover Oracle: Minecraft Seed Search from Software to Quantum Hardware

> **Source:** Originally published on [arXiv quant-ph](https://arxiv.org/abs/2610.33139) on October 27, 2026.

arXiv:2610.33139v1 Announce Type: new Abstract: We present the resource estimation of how known-constant arithmetic changes the cost of a Grover oracle for Minecraft 1.13.1 seed recovery, an application of quantum search to procedural content generation. The oracle developed here combines a structure-placement predicate with a reversible inverse transform of the linear congruential generator for the 32-bit residual search. Reduced-width arithmetic, phase marking, uncomputation, and complete Grover loops are verified against an independent Java reference, while production-width circuits are structurally audited.
