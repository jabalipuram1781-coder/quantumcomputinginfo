# Topological Quantum Error-Correcting Thresholds of a Symmetry-Enriched Toric Code

> **Source:** Originally published on [arXiv quant-ph](https://arxiv.org/abs/2610.37791) on October 30, 2026.

arXiv:2610.37791v1 Announce Type: new Abstract: We study the error thresholds of a new topological quantum error-correcting code under the independent bit-flip and phase-flip noisy channel. By mapping to classical spin-glass models, we find that if Pauli X and Z errors are equally probable, the threshold of vertex syndromes is improved by 30% compared to that of the toric code, while the threshold of plaquette syndromes is lowered. Both thresholds increase when the Z component is less likely than the X component, reaching 0.5 if the Z component is absent. An analytical proof justifies this special case of perfect correctability, and a disordered version of Peierls's argument establishes a lower bound for the vertex-syndrome threshold....
