# Local Clifford equivalence to CSS codes: Polynomial-time classification and conversion

> **Source:** Originally published on [arXiv quant-ph](https://arxiv.org/abs/2610.28737) on October 22, 2026.

arXiv:2610.28737v1 Announce Type: new Abstract: Calderbank--Shor--Steane (CSS) codes support decoding and fault-tolerant logical operations through separate pure $X$ and pure $Z$ stabilizer checks. Generator choices and single-qubit Clifford transformations can obscure this structure. We give a deterministic polynomial-time algorithm that decides whether an arbitrary stabilizer code is locally Clifford-equivalent to a CSS code and constructs the required transformation and CSS checks whenever such a form exists. For $m$ possibly redundant generator rows on $n$ qubits, the algorithm uses $O(mn^2+n^4)$ binary field operations.
