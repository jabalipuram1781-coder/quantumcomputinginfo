# Open Quantum Launches Native Qrisp Integration for High-Level QPU Execution Across IonQ, Rigetti, IQM, and AQT Hardware

> **Source:** Originally published on [Quantum Computing Report](https://quantumcomputingreport.com/open-quantum-launches-native-qrisp-integration-for-high-level-qpu-execution-across-ionq-rigetti-iqm-and-aqt-hardware/) on October 17, 2026.

Open Quantum has launched a native Qrisp integration, enabling high-level QPU execution across IonQ, Rigetti, IQM, and AQT hardware. This allows developers to compile and execute Qrisp programs directly on physical QPUs without writing vendor-specific gate-level code. The integration simplifies quantum programming by providing software-engineering abstractions, automated qubit allocation, and memory management.
