# RhymeQ Emerges from Stealth with $2.2 Million Pre-Seed Round to Launch Python Abstraction Layer for Quantum Computing

> **Source:** Originally published on [Quantum Computing Report](https://quantumcomputingreport.com/rhymeq-emerges-from-stealth-with-2-2-million-pre-seed-round-to-launch-python-abstraction-layer-for-quantum-computing/) on October 22, 2026.

Quantum software startup RhymeQ secured $2.2 million in pre-seed funding to develop Rhyme, a high-level quantum programming platform. Rhyme allows developers to program quantum software using Python, abstracting away low-level quantum circuit details. The platform compiles to NVIDIA CUDA-Q, enabling execution across various quantum hardware and simulators.
