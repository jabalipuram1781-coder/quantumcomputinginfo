# Gothenburg and Chalmers Researchers Develop Modular Graph Neural Decoder for Surface Code Memory and Lattice Surgery

> **Source:** Originally published on [Quantum Computing Report](https://quantumcomputingreport.com/gothenburg-and-chalmers-researchers-develop-modular-graph-neural-decoder-for-surface-code-memory-and-lattice-surgery/) on October 29, 2026.

Researchers from the University of Gothenburg and Chalmers University of Technology have developed a modular neural decoder for surface code quantum error correction (QEC). This decoder demonstrates superior performance compared to traditional methods and is capable of adapting across different hardware architectures, noise profiles, and multi-patch logical operations. Its efficient design, inspired by the renormalization group, allows for training on a single commercial GPU and offers portability advantages for fault-tolerant computing.
