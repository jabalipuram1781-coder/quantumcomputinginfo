# Pasqal Demonstrates Hybrid GPU-to-QPU Workflows Using Slurm 26.11 Hierarchical Resources, QRMI, and CUDA-Q

> **Source:** Originally published on [Quantum Computing Report](https://quantumcomputingreport.com/pasqal-demonstrates-hybrid-gpu-to-qpu-workflows-using-slurm-26-11-hierarchical-resources-qrmi-and-cuda-q/) on November 17, 2026.

Pasqal has developed an integration that allows Slurm 26.11 to schedule jobs across both GPUs and QPUs (quantum processing units), utilizing NVIDIA's Slurm Hierarchical Resources and the Quantum Resource Management Interface (QRMI). This system automates the management of neutral-atom QPUs alongside classical GPUs, enabling multi-stage batch pipelines that can validate quantum simulations on GPUs before executing them on physical quantum hardware. This advancement streamlines hybrid quantum-classical workflows for HPC environments.
