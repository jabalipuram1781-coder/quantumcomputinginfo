# Quantum Machines Demonstrates Sub-Microsecond Surface-Code Decoding on OPX1000 Using NVIDIA CUDA-Q QEC and NVQLink

> **Source:** Originally published on [Quantum Computing Report](https://quantumcomputingreport.com/quantum-machines-demonstrates-sub-microsecond-surface-code-decoding-on-opx1000-using-nvidia-cuda-q-qec-and-nvqlink/) on November 17, 2026.

Quantum Machines demonstrated sub-microsecond surface-code decoding on its OPX1000 platform by integrating NVIDIA CUDA-Q QEC and NVQLink. This achieved a 2.4 μs round-trip communication latency and sub-microsecond per-round decoding for code distances 7 and 11. Early access to this integration will be available to customers in December 2026.
