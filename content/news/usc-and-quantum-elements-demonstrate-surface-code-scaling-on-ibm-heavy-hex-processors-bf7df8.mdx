# USC and Quantum Elements Demonstrate Surface Code Scaling on IBM Heavy-Hex Processors

> **Source:** Originally published on [Quantum Computing Report](https://quantumcomputingreport.com/usc-and-quantum-elements-demonstrate-surface-code-scaling-on-ibm-heavy-hex-processors/) on September 18, 2026.

USC and Quantum Elements successfully demonstrated subthreshold surface code scaling on IBM Heavy-Hex processors, overcoming connectivity challenges with a "fold-unfold" SWAP embedding and robust dynamical decoupling. This work, published in Nature Communications, validates that physical quantum processors can achieve distance-scaling error suppression on non-native geometries and introduces a SPAM-aware Entanglement Fidelity metric for accurate logical error rate assessment. The research utilized 156-qubit IBM Heron processors and builds upon their previous collaborative work in classical digital-twin simulation.
