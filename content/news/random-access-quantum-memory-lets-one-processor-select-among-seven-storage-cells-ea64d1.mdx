# Random access quantum memory lets one processor select among seven storage cells

> **Source:** Originally published on [Phys.org Quantum Physics](https://phys.org/news/2026-09-random-access-quantum-memory-processor.html) on September 25, 2026.

Classical computers can temporarily store the information required to perform specific tasks in a short-term memory component known as RAM (random access memory). This component allows computer processors to retrieve information from a chosen location without searching through all stored data.
