# ParityQC Launches Parity Twine Optimizer via IBM Qiskit Functions Catalog

> **Source:** Originally published on [Quantum Computing Report](https://quantumcomputingreport.com/parityqc-launches-parity-twine-optimizer-via-ibm-qiskit-functions-catalog/) on September 16, 2026.

ParityQC has launched the Parity Twine Optimizer, a new compiler available through the IBM Qiskit Functions Catalog. This technology aims to improve quantum computing by natively mapping optimization problems to quantum hardware, thereby eliminating classical SWAP gate overhead and reducing circuit depth. It supports various hardware topologies and offers a 30-day free trial for IBM Quantum Network members.
