# Horizon Europe Launches €5M ($5.67M USD) Q-VERSE Consortium to Build Hardware-Agnostic Quantum Software Stack

> **Source:** Originally published on [Quantum Computing Report](https://quantumcomputingreport.com/horizon-europe-launches-e5m-5-67m-usd-q-verse-consortium-to-build-hardware-agnostic-quantum-software-stack/) on September 29, 2026.

The Horizon Europe Q-VERSE consortium, funded with €5 million, is developing an open, hardware-agnostic quantum software stack. This initiative aims to unify quantum application development by decoupling it from low-level QPU architectures, utilizing the Eclipse Qrisp framework and standardized intermediate representations. The project, led by Fraunhofer FOKUS, involves 13 partners and will validate its platform across five industrial use cases, including railway scheduling and financial optimization.
