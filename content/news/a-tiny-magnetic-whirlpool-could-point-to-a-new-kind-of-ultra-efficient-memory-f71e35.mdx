# A tiny magnetic whirlpool could point to a new kind of ultra-efficient memory

> **Source:** Originally published on [Phys.org Quantum Physics](https://phys.org/news/2026-10-tiny-magnetic-whirlpool-kind-ultra.html) on October 14, 2026.

Every time a computer stores or erases information, it uses energy. The amount is tiny for a single operation, but those operations happen billions of times every second. For decades, scientists have wondered just how little energy a memory device could use before reaching the fundamental theoretical limit set by the laws of physics. Now, researchers have shown that it is possible to come close.
