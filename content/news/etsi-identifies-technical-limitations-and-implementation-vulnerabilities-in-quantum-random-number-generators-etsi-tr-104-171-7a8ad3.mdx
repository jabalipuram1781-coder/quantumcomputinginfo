# ETSI Identifies Technical Limitations and Implementation Vulnerabilities in Quantum Random Number Generators (ETSI TR 104 171)

> **Source:** Originally published on [Quantum Computing Report](https://quantumcomputingreport.com/etsi-identifies-technical-limitations-and-implementation-vulnerabilities-in-quantum-random-number-generators-etsi-tr-104-171/) on September 26, 2026.

ETSI's new report, TR 104 171, addresses vulnerabilities in Quantum Random Number Generators (QRNGs) due to practical hardware limitations. It provides guidelines across the QRNG lifecycle, including the Entropy Zero Trust (EZT) framework to mitigate side-channel attacks. The report also sets priorities for future standardization, such as API command sets and integration with post-quantum cryptography.
