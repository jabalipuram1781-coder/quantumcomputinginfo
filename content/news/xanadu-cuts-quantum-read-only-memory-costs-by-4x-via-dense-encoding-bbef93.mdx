# Xanadu Cuts Quantum Read-Only Memory Costs by ~4x via Dense Encoding

> **Source:** Originally published on [Quantum Computing Report](https://quantumcomputingreport.com/xanadu-cuts-quantum-read-only-memory-costs-by-4x-via-dense-encoding/) on October 10, 2026.

Xanadu has achieved a nearly 4-fold reduction in Quantum Read-Only Memory (QROM) costs by developing an algorithmic technique that reduces the non-Clifford gate cost. This was accomplished through two innovations: Sequential Bit Packets and SelectCopy, and Dense Encoding in Z and X Bases. These advancements significantly cut hardware runtimes and qubit requirements for loading classical data into quantum computers.
