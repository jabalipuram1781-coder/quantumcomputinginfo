# Quantinuum Demonstrates 99.9995% Logical Memory Fidelity on Helios Trapped-Ion Processor

> **Source:** Originally published on [Quantum Computing Report](https://quantumcomputingreport.com/quantinuum-demonstrates-99-9995-logical-memory-fidelity-on-helios-trapped-ion-processor/) on October 19, 2026.

Quantinuum has demonstrated a 99.9995% logical memory fidelity on its Helios trapped-ion quantum computer, achieving a logical error rate of 5 × 10-6 per syndrome-extraction round on a distance-7 code. This performance shows exponential error suppression with increasing code distance, with a suppression factor of 12. These results align with the performance targets for Quantinuum's future universal fault-tolerant quantum system, Apollo.
