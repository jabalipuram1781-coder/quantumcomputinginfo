# ICTK and Jiran Security Partner on ‘Q-BRIDGE’ to Commercialize End-to-End PQC Migration Frameworks

> **Source:** Originally published on [Quantum Computing Report](https://quantumcomputingreport.com/ictk-and-jiran-security-partner-on-q-bridge-to-commercialize-end-to-end-pqc-migration-frameworks/) on September 18, 2026.

ICTK and Jiran Security have partnered to launch Q-BRIDGE, an initiative offering end-to-end Post-Quantum Cryptography (PQC) migration for enterprises, governments, and financial sectors. Jiran Security will handle diagnostic auditing, risk assessment, and migration planning, while ICTK will provide hardware-rooted PQC security architecture using its VIA PUF™ (Physically Unclonable Function) Hardware Root of Trust (HRoT) chips. This collaboration aims to streamline PQC transitions by integrating cryptographic inventory discovery with physical PUF-PQC hardware deployment.
