# EigenOrbit Releases Open-Source eigenkit 1.0 for Multi-Backend Quantum Execution

> **Source:** Originally published on [Quantum Computing Report](https://quantumcomputingreport.com/eigenorbit-releases-open-source-eigenkit-1-0-for-multi-backend-quantum-execution/) on October 14, 2026.

EigenOrbit has released eigenkit 1.0, an open-source Python library. It allows quantum algorithms to be written once and executed across multiple simulators and hardware backends without code modification. The library integrates with various classical simulators and QPU hardware access points, including machine learning and cost tools.
